# v0.2.0 — Seedream 生图与编辑、画质选择和总等待预算

此版本整理已部署的 Seedream 适配、`quality` 路由和等待预算修复，并补齐 MCP 可发现的编辑说明与服务版本。

## MCP 调用方如何更新

1. 连接已升级的服务，重新执行 `initialize`；`serverInfo.version` 应为 `0.2.0`。
2. 重新执行 `tools/list`，替换调用方缓存的工具描述和参数 schema，并把新定义提供给模型。
3. `generate_image` 和 `list_models` 的工具名不变，原有调用参数继续可用。

**发布 GitHub Release 不会自动让现有 MCP 会话或工具缓存更新。** 本服务为 stateless HTTP，不把跨部署的工具刷新依赖于长期会话通知。`GET /v1/health` 和 OpenAPI 也返回 `0.2.0`，便于核对部署版本。

## 生图与画质选择

- 默认配置使用 Seedream 5.0 Flash，备用为 Gemini → Qwen。
- `quality="standard"` 选择 Flash，`quality="high"` 选择 Pro。
- 显式 `model` 优先；`model` 和 `quality` 均省略时使用 `DEFAULT_MODEL`。
- 画质偏好与 `size` 分别控制模型和像素预算。返回的 `model` 是实际出图模型，`requested_model` 是解析后的初始模型。

相关改动：[Seedream 适配 #27](https://github.com/HyxiaoGe/image-service/pull/27)、[画质路由 #29](https://github.com/HyxiaoGe/image-service/pull/29)。

## 图片编辑

现有 `generate_image` 已能接收原图 URL 和编辑指令；本次把基础编辑、连续编辑和坐标编辑用法明确写进 MCP 工具描述。服务无需新增编辑端点：

```json
{
  "prompt": "只编辑图1 <bbox>400 420 610 620</bbox> 区域，在杯身添加金色星标，尽量保留其他部分。",
  "reference_images": ["https://images.example.com/original.jpg"],
  "quality": "standard",
  "aspect_ratio": "1:1",
  "size": "1024x1024",
  "fallback_model": "none"
}
```

- 示例 URL 需替换为可访问原图或本服务返回的完整 `image_url`。
- 下一轮编辑，把上一轮的 `image_url` 重新放进 `reference_images`；每次返回新图片。
- Flash / Pro 的 `<point>`、`<bbox>` 使用相对整张输入图的 0–999 归一化坐标。依赖该供应商语法时关闭跨供应商备用。
- 默认输出比例为 1:1；要保留输入形状，显式传原图比例。
- 坐标编辑属于生成式重绘，不保证框外像素不变。当前服务未开放上传文件、`mask` / `strength`、图层数组或透明输出控制。

在 dev 已验证换背景、Flash / Pro 框选添加图案、再引用结果移除图案，共四张真实结果。详情见[编辑调研记录](https://github.com/HyxiaoGe/image-service/blob/v0.2.0/docs/SEEDREAM_EDITING_RESEARCH.md)。

## 总等待预算与取消

- 默认总预算 135 秒，覆盖参考图、缓存 / 锁等待、主备调用与有界清理。
- 普通模型默认执行上限 60 秒、Seedream Pro 105 秒，实际受剩余总预算限制。
- 优先给首个备用预留其完整执行上限，并以 `FALLBACK_RESERVE_SECONDS` 为最低预留配置；预算不足时按剩余时间决定执行。
- 生图读写超时不再重发同一模型，剩余预算允许时可切备用。HTTP / MCP 断连与取消会停止本地等待及后续尝试。
- 供应商已接受的请求仍可能完成并计费；停止本地等待不保证供应商取消或退费。关闭备用可传 `fallback_model="none"`。

相关改动：[总预算与取消 #30](https://github.com/HyxiaoGe/image-service/pull/30)、[备用完整执行预算 #31](https://github.com/HyxiaoGe/image-service/pull/31)。
